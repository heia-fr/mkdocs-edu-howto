# {{ page.title }}

Le but de ce site est de vous apprendre à faire un site web pour votre enseignement.

![Un site pour apprendre à faire un site](img/inception.jpeg){ width="100%" }

!!! info
    Ce site est lui même un site de démonstration avec les fonctionnalités que nous allons présenter.
    Vous pouvez consulter le code source de ce site sur [GitHub](https://github.com/heia-fr/mkdocs-edu-howto)

!!! warning
    Le projet MkDocs utilisé à l'origine pour ce site traverse une
    [crise existentielle majeure](https://fpgmaas.com/blog/collapse-of-mkdocs/). Dans la nouvelle version
    du site que vous êtes en train de lire, nous avons remplacé MkDocs par [ProperDocs](https://properdocs.org/),
    un _fork_ de MkDocs qui devrait amener un peu de stabilité dans le développement du projet. Nous avons aussi
    remplacé Poetry par [uv](https://docs.astral.sh/uv/) et remplacé le thème _Material for MkDocs_ par [MaterialX](https://jaywhj.github.io/mkdocs-materialx/)

    Ce n'est pas impossible que vous rencontriez encore des références à MkDocs car les _plugins_ que nous utilisons sont encore développés pour MkDocs. N'hésitez pas à nous signaler les anciennes références à MkDocs que vous pourriez trouver.
